鑑賞記録

私は作品鑑賞が好きなので、今まで見た作品を自分用に記録するようにしました (浪人のころから記録をつけ始めたので、高校卒業までに見たものはここには書いていません)。

ちなみに一番好きな映画はビューティフル・マインドです。これはもう最強です。

凡例　面白かった作品：☻　つまらなかった作品：☠　殿堂入り：♥

  • 前科者 --新米保護司・阿川佳代-- [テレビドラマ, ロマンス]
  • ☻中学聖日記 [テレビドラマ, ロマンス]
  • ☻ 花束みたいな恋をした [映画, ロマンス]
  • SPEC [テレビドラマ, SF]
  • ☠ プラダを着た悪魔2 [映画, ドラマ]
    　申し訳ないが、つまらなかった。1が良過ぎてハードルが上がり過ぎたか。
  • アン・ハサウェイ 裸の天使 [映画, ドラマ]
  • プリティウーマン [映画, ロマンス]
  • ☠ フォレスト・ガンプ [映画, コメディ]
    　全く面白くない。
  • ☠☠ キル・ビル1 [映画, アクション / コメディ]
    　全く面白くない。若い頃の栗山千明が見れるだけの作品。
  • ザ・エージェント [映画, ドラマ]
  • ♥バニラ・スカイ [映画, SF / ドラマ / ロマンス]
    　これは面白い。2000年代のトムクルーズの顔面偏差値が異常に高く、ストーリーもいい。どうやらスペイン映画のリメイクらしいのでそちらも見て比較してみたい。
  • プラットフォーム [映画, SF]
    　社会風刺が多い映画。普通。
  • ☻エターナル・サンシャイン [映画, ドラマ / ロマンス]
    　面白い。ただ、中年になったら見方が変わると思う。
  • 野火 [映画, 戦争]
  • ☻キャッチ・ミー・イフ・ユー・キャン [映画, クライム]
    　レオナルド・ディカプリオはタイタニックだけしかヒットしなかった感じがするが、全然そんなことはなく、こちらも面白い。何よりも本作が事実に基づいているのが驚きだ。
  • ☻プラダを着た悪魔 [映画, ドラマ]
    　ストーリーは全く面白くないが、ここまでお金をかけた映像を見せられると流石に印象に残る。
  • MONDAYS / このタイムループ、上司に気づかせないと終わらない [映画, コメディ / SF]
  • ☻Fall [映画, サスペンス]
  • ☻ウルフ・オブ・ウォールストリート [映画, コメディ]
    　なんてお下品な映画。でも面白い。
  • 告白 [映画, ミステリー]
  • ナミビアの砂漠 [映画, ドラマ]
  • ☻さよならドビュッシー [映画, ミステリー]
    　面白い。ストーリーがいい。
  • ☻ショーシャンクの空に [映画, ドラマ]
  • 早乙女カナコの場合は [映画, ロマンス / ドラマ]
  • 関心領域 [映画, 戦争 / シリアス]
  • ☻PERFECT DAYS [映画, 日常]
  • ☻グリーンブック [映画, 差別 / ドラマ]
  • 桐島、部活やめるってよ [映画, 青春]
  • ☻何者 [映画, 青春 / 就活]

  • ☻ビンゴ [映画, サスペンス]
    　リアル鬼ごっこを書いた人が原作らしい。俳優にもっとお金をかけたらいい映画になったと思う。演技が下手過ぎて、見ていて冷めちゃう部分が多かった。
  • ☻大逆転 [映画, ドラマ]
  • ☻コラテラル [映画, クライム / サスペンス / アクション]
  • ♥きっと、うまくいく [映画, ドラマ]
    　浪人のころに見た。インド映画なので途中に何回もダンスシーンが挟まる。映画は3時間もあるが、ダンスシーンをカットすれば2時間半には収まるんじゃないだろうか。言い過ぎ？

    　ホーキング博士の生涯を描いた作品。
  • ソーシャル・ネットワーク [映画, ドラマ]
    　マークザッカーバーグを描いた作品。
  • ♥♥♥ビューティフル・マインド [映画, サスペンス]
    　浪人しているときに見たのだが、これは本当に面白い。内容に少しでも触れてしまえばネタバレになってしまうので避けるが、本当に面白い映画。ラッセル・クロウとジェニファー・コネリーは両者ともに好きな演者なので見ていて楽しかった。この映画に関してはもう10回くらいは見た。ストーリーはすべて覚えているのに、何回見ても面白い。
